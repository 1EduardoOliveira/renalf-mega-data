# Renalf Mega Data

Projeto acadêmico desenvolvido em linguagem C para praticar conceitos de **Estrutura de Dados**, utilizando uma **lista simplesmente encadeada**.

## Sobre o projeto

O sistema simula o gerenciamento de usuários de uma empresa fictícia chamada Renalf Mega Data.

A estrutura permite armazenar e manipular registros dinamicamente por meio de nós conectados por ponteiros.

## Funcionalidades

- Inclusão de usuários;
- Consulta de usuários;
- Alteração de registros;
- Remoção de usuários.

## Dados armazenados

- Nome;
- CPF;
- Data de nascimento.

## Tecnologias e conceitos

- Linguagem C;
- Listas simplesmente encadeadas;
- Ponteiros;
- Alocação dinâmica de memória (`malloc`);
- Liberação de memória (`free`).

## Como executar

Compile o código utilizando GCC:

```bash
gcc main.c -o programa
```

Execute:

```bash
./programa
```

## Objetivo acadêmico

Aplicar na prática os conceitos de listas encadeadas e manipulação dinâmica de dados estudados na disciplina de Estrutura de Dados.
